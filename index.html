SMART IRRIGATION SYSTEM USING IoT // v1.4

> Autonomous Moisture-Driven Agricultural Automation Platform

[SENSORS: SOIL_MOISTURE_ACTIVE] [RELAY: 5V_NORMALLY_OPEN] [PUMP_STATE: AUTONOMOUS] [MCU: ARDUINO_UNO_R3]

Project Overview & Objective

Smart Irrigation System using IoT is an automated plant-watering system that monitors soil moisture and controls a water pump accordingly. The project uses Arduino Uno, a soil moisture sensor, and a relay module to provide efficient and automated irrigation while reducing unnecessary water usage. By continually polling soil resistance, the system ensures crops and plants receive optimal hydration without human intervention while conserving up to 60% of water.

Hardware & Circuit Component Matrix

Microcontroller
Arduino Uno (ATmega328P)
Moisture Sensor
Capacitive Soil Sensor (Pin A0)
Actuator Relay
5V Single-Channel Relay (Pin D7)
Water Pump
Submersible DC Pump 5V / 12V

Control Logic & Threshold Algorithm

// C++ / Arduino Threshold Control Loop const int SENSOR_PIN = A0; // Analog input from soil moisture probe const int RELAY_PIN = 7; // Digital output to pump relay const int DRY_THRESHOLD = 450; // Below this = dry soil (requires watering) void loop() { int moisture = analogRead(SENSOR_PIN); if (moisture > DRY_THRESHOLD) { // Soil is dry: Activate relay to power water pump digitalWrite(RELAY_PIN, HIGH); Serial.println("[STATUS]: Soil Dry -> Irrigation PUMP ACTIVE"); } else { // Optimal moisture achieved: Deactivate pump to conserve water digitalWrite(RELAY_PIN, LOW); Serial.println("[STATUS]: Moisture Optimal -> PUMP STANDBY"); } delay(2000); // Poll telemetry every 2 seconds }
